# Data Sources

All data in `data/` is collected from publicly available grant program disclosures and is licensed under [CC BY 4.0](../data/LICENSE).

## Programs

### Optimism RPGF

- **Rounds ingested:** 1, 2, 3, 4
- **Source:** Public round result disclosures from the Optimism Collective
- **Source URL:** https://optimism.io/rpgf
- **Original license:** Public disclosure / CC-BY (per OP Collective norms)
- **Takedown contact:** grants-registry@giveprotocol.org

### Gitcoin Grants

- **Rounds ingested:** GR15 and later
- **Source:** Gitcoin public APIs and round data exports
- **Source URL:** https://gitcoin.co/grants
- **Original license:** Public / open data
- **Takedown contact:** grants-registry@giveprotocol.org

### Ethereum Foundation ESP

- **Rounds ingested:** Best-effort from public disclosures
- **Source:** EF ESP blog posts and public grantee announcements
- **Source URL:** https://esp.ethereum.foundation
- **Original license:** Public disclosure
- **Notes:** Coverage is incomplete; gaps are flagged in the data.
- **Takedown contact:** grants-registry@giveprotocol.org
